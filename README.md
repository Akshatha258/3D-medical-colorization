# 2D to 3D Medical Image Colorization

This project converts 2D grayscale MRI brain slices into colorized images using deep learning and reconstructs them into a 3D volume.

## Features
- 2D image colorization using deep learning
- 3D brain volume reconstruction
- Orthogonal views (Axial, Coronal, Sagittal)
- Web-based interface using HTML

## Technologies Used
- Python
- Deep Learning (U-Net / CNN)
- OpenCV
- NumPy
- HTML/CSS

## Files
- app.py → main application
- brain_mri_3d.py → 3D reconstruction
- colorizer.py → colorization model
- volume.py → volume processing
- index.html → frontend UI

## Output
- Colorized MRI slices
- 3D reconstructed brain visualization
